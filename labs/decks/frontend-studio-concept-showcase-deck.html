01 / 10
concept map

대비가 강해야 선택지도 의미가 생긴다

따뜻함 ↔ 차가움

Claude는 학습과 설득에 강하고, Vercel/Stripe는 실행 상태와 신뢰에 강하다.

밝은 캔버스 ↔ 검은 콘솔

Miro는 워크숍, NVIDIA/Bugatti는 기술 밀도와 집중감을 만든다.

문서형 ↔ 런타임형

설명 자료는 editorial, 제품 데모는 console, 의사결정 회의는 board가 맞다.

친근한 교육 ↔ 임원 브리핑

같은 내용을 누구에게 보여주느냐에 따라 화면 언어가 달라진다.

상태 강조 ↔ 사고 과정 강조

Deploy/Green은 상태, Warm/Board는 과정과 학습을 잘 보여준다.

표준화 ↔ 기억성

브랜드 참조는 복제가 아니라, 기억되는 정보 구조를 고르는 일이다.

frontend-studio workflow

핵심은 예쁜 색을 고르는 것이 아니라, 작업에 맞는 화면 언어를 고르는 것

1. 목적

청중, 산출물, 완료 기준을 정한다.

2. reference

$get-design으로 방향을 고른다.

3. build

웹 UI 또는 slide HTML로 구현한다.

4. verify

desktop/mobile overflow와 contrast를 본다.

5. reuse

반복되면 custom Skill로 승격한다.
